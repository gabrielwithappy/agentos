# Supporting Documents

구현 근거는 `implementation/`, 결정·리뷰 근거는 `decisions/`, 운영·복구 절차는 `operations/`에 둔다. 최소 카테고리는 이 세 디렉터리다. 모든 supporting document와 supporting docs는 `00-project-index.md`에 등록하고 active execution plan에서 참조한다.

Supporting documents are evidence only and do not override root project documents, active plans, `AGENTS.md`, vendor guides, protected-path rules, reviewer authority, or human approval requirements.
